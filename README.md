# Nextcloud Secure Office

Plugin / Aplicación para Nextcloud 33 que proporciona integración y funcionalidades seguras para documentos ofimáticos.

## Estructura de la aplicación

* `appinfo/`: Metadatos (`info.xml`), configuración y rutas (`routes.php`).
* `lib/`: Código fuente PHP (Controladores, Servicios, Listeners).
* `templates/`: Plantillas para la interfaz gráfica.
* `img/`: Iconos y recursos gráficos.

## Requisitos

* Nextcloud >= 33.0.0
* PHP >= 8.2
